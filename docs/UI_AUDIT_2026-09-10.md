## 四、遗留事项

- 模拟器为一台 x86_64 AVD（伪装 OnePlus HD1910 属性）：debug 调试需
  `flutter build apk --debug --target-platform android-x64`；真机（arm64）用
  `--target-platform android-arm64`。**真机实测待用户连接物理设备后进行。**
- 服务端（MicroTripServer）暂无 `DELETE /api/v1/auth/account`：
  客户端注销入口在演示模式完全可用；云端模式返回失败并提示重试，
  **上架前需在服务端补齐该接口**（见 RELEASE 清单）。
